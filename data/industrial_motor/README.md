# 工业电机案例数据

原始来源：[Zhao et al., PLOS ONE 21(5), e0348884 (2026)](https://doi.org/10.1371/journal.pone.0348884)，第 15 页 Section 5、Tables 1–3。`source/` 为未经修改的开放获取论文及下载日期、SHA-256 和来源许可说明。文献将该案例追溯至 Changzhou AMEC&GBM Motor Company；本项目没有现场测量或企业部署记录。

- `extracted/published.json`：人工对照原始 PDF 提取并核验的数值，包括未纳入重构模型的原始约束。
- `extracted/cost_fit.csv`：原产品切换成本、加性拟合值及逐项误差，单位千元。
- `derived.json`：完整模块参数、时间刻度、来源标签与建模假设。
- `instances/MOTOR_FULL/`：16 件产品、80 道加工任务。
- `instances/MOTOR_SMOKE/`：每类 1 件产品、20 道任务，仅用于功能验证。

“公开值”表示文献报告值，并非本项目独立验证的厂内原始记录。产品专用逻辑模块、五等分工位成本和模糊装卸时间均为重构或推导参数，不能称为实测数据。论文原始成本包含周期末回切，本项目采用有限周期而不计回切；重算原矩阵成本时采用相同边界。

生成、训练和结果说明见[根 README](../../README.md#工业电机案例)。源 PDF 依据论文开放获取声明保存并注明作者，未修改其内容；本目录不宣称拥有源论文版权。
